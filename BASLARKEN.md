# Yeni Frontend Projesi

Bu repo bir sablon. "Use this template" ile yeni proje ac.

## Yapilacaklar

- [ ] README.md'yi duzenle (proje adi, aciklama)
- [ ] .env.example'i projeye gore duzenle
- [ ] develop branch olustur
- [ ] Projeyi scaffold et (npx create-next-app, npm create vite, vb.)
- [ ] npm install && ilk commit
- [ ] Trello board olustur
- [ ] Slack #proje-[ad] kanali ac
- [ ] Bu dosyayi (BASLARKEN.md) sil
